# بروتوكول الفريق الخماسي الذاتي لمنصة Tashil Data Sharing
## Autonomous Multi-Agent Team Orchestration Standard

يتم تفعيل هذا البروتوكول **تلقائياً وبشكل دائم** عند استقبال أي طلب، ميزة، تحسين، أو إصلاح داخل هذا المشروع، دون حاجة إلى تذكير المستخدم بتشغيل الوكلاء.

### بروتوكول التنفيذ التلقائي لكل طلب (Execution Lifecycle)

1. **الخطوة 1: التحليل وتحديد العقد (Contract-First Definition):**
   - يقوم القائد المعماري بضبط مدخلات ومخرجات الميزة، وتحديد حقول الـ JSON والنماذج المشتركة لمنع تعارض الوكلاء.
2. **الخطوة 2: التنفيذ المتوازي المعزول (Isolated Parallel Implementation):**
   - ينفذ مهندس الباك إند مسارات الـ Go و BigQuery في `backend-go/`.
   - ينفذ مهندس الواجهات شاشات ومكونات M3 في `tashil_web/` مع مراعاة RTL والـ 8dp.
3. **الخطوة 3: التدقيق الأمني وعزل البيانات (Security Gate):**
   - يدقق وكيل الأمان استعلامات الـ RLS ومعاملات `tenant_id` وحماية خصوصية السلاسل.
4. **الخطوة 4: الفحص الآلي الذاتي (Automated Verification Gate):**
   - يشغل مهندس الجودة الاختبارات الآلية (`go test`, `flutter test`, `flutter analyze`). وفي حال وجود أي خطأ، يتم تصحيحه ذاتياً في الخلفية (Self-Healing Loop) قبل إبلاغ المستخدم.
5. **الخطوة 5: التلخيص التنفيذي والتسليم (Executive Delivery):**
   - يقدم القائد للمستخدم تقريراً موجزاً ومباشراً يوضح ما تم إنجازه مع توثيق نتائج الاختبارات وخطوات التجربة.
